# PROTEIN STUDIO APP

Единое приложение PROTEIN STUDIO для клиента, консультанта и администратора.

## Уже заложено
- регистрация клиента и выбор консультанта;
- профиль-оценка перед входом;
- «Мой план» как главный раздел;
- питание и тренировки;
- марафон и прогресс;
- достижения и сообщество;
- связь с консультантом;
- настройки уведомлений;
- профиль;
- Supabase Auth и единая база;
- PWA для установки на телефон.

## Архитектура
Один проект и одна база Supabase. Интерфейс будет зависеть от роли: client / consultant / admin.

Публичные параметры Supabase не хранятся в репозитории. При первом запуске приложение показывает одноразовый экран подключения.
