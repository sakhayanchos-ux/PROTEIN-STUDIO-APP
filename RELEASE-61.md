# PROTEIN STUDIO · release 61

## Добавлено
- «Забыли пароль?» с безопасным восстановлением через одноразовый код, который подтверждает консультант.
- Универсальный редактор фотографий перед загрузкой: масштаб, перемещение и формат кадра. Работает для профиля, фото ДО/ПОСЛЕ и других фото-загрузок.
- В прогрессе можно указать дату начала пути; стартовый вес и стартовая талия добавляются в график и таблицу замеров.
- Дни прогресса и коллаж считаются от даты старта до текущей даты.
- Коллаж теперь показывает маршрут веса «старт → сейчас».
- Меню PROTEIN STUDIO открывается сразу с консультантом клиента через персональный ref.
- В Питании, Воде, Тренировках и Темах есть кнопка «← Назад в Мой план».
- «Моя история» полностью переделана: только свободные текстовые ответы.
- Для истории результата вопросы разделены на 3 части: «До PROTEIN STUDIO», «Что начали делать», «Что изменилось».
- После анкеты создаются 3 редактируемые версии: 30 секунд, 1 минута, 2–3 минуты.
- У консультанта доступны две истории: «Моя история результата» и «Моя история консультанта», каждая в трёх версиях.
- Консультант видит истории своих клиентов в карточке клиента.
- Первая история результата клиента по-прежнему даёт +2⭐ только один раз.

## Supabase
- Добавлено поле ps_assessments.progress_start_date.
- Добавлена таблица ps_password_reset_requests с RLS и без прямого доступа клиента.
- Добавлены RPC ps_save_story_v58 и ps_update_story_versions_v58.
- Развёрнута Edge Function ps-password-reset для запроса, подтверждения и завершения восстановления пароля.

## Проверки
- Синтаксис изменённых JavaScript-файлов проверен.
- Существующие профили, замеры, фото, сообщения и старые истории не удалялись.
